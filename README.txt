GIO'S RANDOM UPLOADS  (a part of Gio's Wacky Projects)

Structure
  index.html            home page with the uploads column
  deepest-part/         the audiobook page
  media/                ALL files live here, one subfolder per upload
    deepest-part/       audio (.m4a), cover.jpeg, Text_story.txt

To add a new upload
  1. Make media/<name>/ and drop your files in.
  2. Make <name>/index.html for its page (copy deepest-part/index.html as a start).
  3. Add an entry to the "uploads" list at the top of the script in index.html.

To publish (Cloudflare Pages): upload the CONTENTS of this folder.
